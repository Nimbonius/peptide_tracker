# Peptide Tracker

A small native Android app for personal peptide-related recordkeeping.

## Track

- Inventory: peptide name, quantity, unit, storage notes, expiration, and price paid
- Dose history: name, amount, unit, date, and notes
- Supplies: item, quantity, and notes

Records are saved locally on the device with Android app preferences. No account or network access is required. This app is a recordkeeping tool only; it does not provide medical, dosing, or storage advice. Follow product labeling and guidance from a qualified healthcare professional.

## Build

Open this folder in Android Studio and allow Gradle sync, then run the `app` configuration on an emulator or Android device. The project uses the Android Gradle plugin and Android SDK; this workspace does not include a Gradle wrapper.
